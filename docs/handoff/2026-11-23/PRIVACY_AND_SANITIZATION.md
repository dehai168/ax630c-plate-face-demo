# 隐私与脱敏

## 本包禁止收录

- 聊天全文
- 密码、口令、SSH 私钥、token、cookies、`.env`
- license 与 `private_root` 发行激活材料
- 个人联系方式、付款信息

可以保留：完成任务所必需的局域网 IP、设备 MAC、项目路径、SSH **公钥指纹**（不是私钥）、公开模型哈希。

板卡密码曾经提供过，**本包故意不收录**。

## 复制规则

精选原文在复制时扫描赋值型口令、私钥块、Bearer token、api/access token。命中则把值换成 `<REDACTED>`，并在台账中记录规则名与替换次数（不记录秘密本身）。含占位符的脚本**不能直接当作可执行脚本使用**。

本批精选复制结果：未触发替换，原件 SHA 与副本 SHA 相同。全包另做一次秘密扫描，见整理记录；扫描日志只报规则与文件路径，不回显秘密。
